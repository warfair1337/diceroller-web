# diceroller-web

Interactive dice rolling web application.

## Features
- Roll up to 25 dice with 6 or 10 sides.
- Optional re-rolls of individual dice or all dice.
- "Bad Gambler" mode biases results toward higher numbers.
- Animated rolls with staggered delays.
- Highlights Doubles, Trips, and Quads when consecutive dice show the same value.

Open `index.html` in a browser to use the app.
